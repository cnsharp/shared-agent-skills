# Document Review Checklist

Verify item by item; for each hit, record as "issue → location → suggestion".

## Structure
- [ ] Top-level heading exists and is unique
- [ ] Heading hierarchy is contiguous, no skips
- [ ] No duplicate heading text
- [ ] Code blocks are labeled with a language and runnable
- [ ] Lists and tables are syntactically closed

## Terminology and Consistency
- [ ] Same concept has consistent spelling/translation
- [ ] Chinese/English punctuation is consistent
- [ ] Number, unit, and date formats are consistent

## Readability and Accuracy
- [ ] No overly long sentences (>60 chars, consider splitting)
- [ ] Passive voice is not overused
- [ ] Example commands/paths are valid and relative

## Links
- [ ] Relative link targets exist
- [ ] Anchor links match their headings
- [ ] No obviously broken external links (optional online verification)
